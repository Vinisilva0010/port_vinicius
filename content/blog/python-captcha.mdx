Você criou o bot perfeito, mas na hora de fazer o login, aparece o maldito quebra-cabeça de trânsito ou o "I'm not a robot". Game over? Não.

Existem serviços (como 2Captcha, AntiCaptcha, DeathByCaptcha) onde tem humanos ou IAs resolvendo isso 24h por dia. Você manda o problema, eles mandam a resposta. Custa centavos (tipo $0.50 para resolver 1.000 captchas).

Para um bot profissional, isso é custo operacional. É a "Chave Mestra".

## Como funciona a Mágica

O Captcha do Google (ReCaptcha V2) funciona assim:
1. O site tem uma chave pública (`sitekey`).
2. Quando você resolve, o Google te dá um `token` gigante.
3. Esse token é enviado num campo escondido (`g-recaptcha-response`) quando você clica em Enviar.

O nosso script não clica nas fotos. Ele pega a `sitekey`, manda pra API resolver, pega o `token` pronto e injeta direto no HTML do site. O site acha que você resolveu.

gosto de usar a biblioteca `requests` pura para entender a lógica (sem depender de libs prontas que quebram).
