# 14/02/2026 - Automação de Mouse

Hoje eu precisei criar um script para mexer o mouse sozinho e não deixar o PC bloquear. Usei a lib `pyautogui`.

```python
import pyautogui
import time

while True:
    pyautogui.moveRel(0, 10)
    time.sleep(1)
